ASSESSMENT STUDIO — CLEAN START

This is a fresh complete project folder. It includes:
- React + Vite app setup
- The supplied Assessment Studio UI and behavior
- A modular src/App.jsx and separate reusable components
- The original supplied styles.css (including the sidebar-hidden CSS overrides)
- styled-components dependency used in Header.jsx

HOW TO RUN:
1. Open this folder (the folder containing package.json) in VS Code.
2. Open Terminal > New Terminal.
3. Run: npm.cmd install
4. Run: npm.cmd run dev
5. Open the localhost address shown in the terminal.

Do not copy only the inner src/components folder. This is a complete project folder.
